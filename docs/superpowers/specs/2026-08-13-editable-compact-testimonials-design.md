# Компактные и редактируемые отзывы

## Цель

Сократить высоту карточек отзывов на мобильных экранах и сделать отзыв Олександра Гостєва обычной редактируемой записью в админ-панели.

## Решение

- `getPublicTestimonials` сохраняет запись с ID `client-business-feedback-2026`, если она уже пришла из D1, и добавляет дефолт только при её отсутствии.
- Админ-страница передаёт в редактор тот же нормализованный список, который видит публичная страница. Поэтому дефолтный отзыв сразу доступен для редактирования и после сохранения попадает в D1.
- Новые отзывы продолжают добавляться существующей кнопкой и сохраняются тем же API без ограничения количества.
- В дефолтном тексте между пунктами остаётся один перенос строки вместо пустой строки.
- На мобильных экранах уменьшаются внутренние отступы карточки, промежуток после автора, аватар, размер текста и межстрочный интервал.

## Границы

- Схема D1 и API сохранения не меняются.
- Новые зависимости и отдельная система отзывов не добавляются.
- Десктопная визуальная стилистика сохраняется.

## Проверка

- Тест подтверждает, что пользовательская редакция фиксированного отзыва не перезаписывается.
- Контрактный тест подтверждает, что админка получает нормализованные отзывы и мобильные стили компактны.
- Полный набор тестов и production-сборка проходят.
